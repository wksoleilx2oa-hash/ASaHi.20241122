1. 吉野桧（床用フローリング）

吉野桧 一枚もの通常品フローリング ¥8,030 / ㎡ (税込 / 税抜 ¥7,300)
寸法：15mm×110mm×1820mm グレード：通常品（節あり・埋木処理） 仕上：無塗装

奈良県産の吉野桧を贅沢に使用した、一枚ものの無垢フローリングです。通常グレードならではの節や抜け節には、目立ちにくくするための埋め木処理を施しています。針葉樹特有のやさしく柔らかな足触りと、吉野桧が醸し出す上品で心地よい香りをお楽しみいただけます。

吉野桧 一枚もの上小節フローリング ¥11,550 / ㎡ (税込 / 税抜 ¥10,500)
寸法：15mm×110mm×1820mm グレード：上小節 仕上：無塗装

直径10mm〜20mm程度の小さな節（上小節）が控えめに現れ、天然木ならではの趣を残しながらも、通常品よりすっきりとした端正で落ち着きのある表情に仕上がっています。また、死節部分には特殊なコマ型埋木処理を施しており、木の風合いを活かしながら、耐久性と美観を兼ね備えた仕上がりを実現しています。

吉野桧 一枚もの無節フローリング ¥18,480 / ㎡ (税込 / 税抜 ¥16,800)
寸法：15mm×110mm×1820mm グレード：無節（最高級） 仕上：無塗装

表面に節がほとんど現れない、桧の中でも最高峰に位置する「無節」グレード。桧特有のきめ細やかでなめらかな木肌に加え、光を受けて美しく際立つ上品な光沢と、端正で繊細な木目が魅力です。

2. 吉野桧（壁・天井パネリング／羽目板）

吉野桧 パネリング通常品 ¥7,480 / ㎡ (税込 / 税抜 ¥6,800)
寸法：12mm×108mm×2000mm グレード：通常品 仕上：無塗装

壁面や天井を美しく彩る、内装用の吉野桧パネリング（羽目板）です。吉野桧ならではのきめ細やかな木肌と、空間を包み込むような清々しく上品な芳香が魅力。桧の自然な香りが心地よい癒しの空間を演出するとともに、木材が持つ防虫性や調湿性も期待できます。

吉野桧 パネリング上小節 ¥9,900 / ㎡ (税込 / 税抜 ¥9,000)
寸法：12mm×108mm×2000mm グレード：上小節 仕上：無塗装

小さな節が控えめに点在する、上小節グレードの吉野桧パネリングです。天然木ならではの趣をほどよく残しながら、節の主張を抑えたすっきりとした表情が魅力。桧の明るく美しい木肌が空間を軽やかに彩り、洗練された印象を与えます。

吉野桧 パネリング無節 ¥16,500 / ㎡ (税込 / 税抜 ¥15,000)
寸法：12mm×108mm×2000mm グレード：無節（最高級） 仕上：無塗装

表面に節がほとんど見られない、最上級の「無節」グレードで仕上げた吉野桧のパネリング材です。整然とした美しい柾目・板目と、桧特有の明るく上品な光沢が際立ち、壁や天井一面に張ることで、空間全体を格調高く演出します。

3. 吉野桧（床暖房兼用フローリング）

吉野桧 一枚もの（床暖房兼用）通常品フローリング ¥10,989 / ㎡ (税込 / 税抜 ¥9,990)
寸法：15mm×110mm×1820mm 仕様：床暖房対応（熱源60℃まで） グレード：通常品 仕上：無塗装

熱源温度60℃までの床暖房に対応した、一枚ものの純国産無垢フローリングです。天然木ならではの豊かな風合いと無垢材の心地よさを楽しみながら、床暖房による快適な暖かさを取り入れられる仕様。床暖房の熱変化によって節が痩せ、抜け落ちることを防ぐため、あらかじめ丁寧な埋木処理を施しています。

吉野桧 一枚もの（床暖房兼用）上小節フローリング ¥15,950 / ㎡ (税込 / 税抜 ¥14,500)
寸法：15mm×110mm×1820mm 仕様：床暖房対応（熱源60℃まで） グレード：上小節 仕上：無塗装

床暖房に対応した、上小節グレードの無垢フローリングです。控えめで小さな節がほどよく現れることで、天然木ならではの趣を残しながらも、すっきりと端正な表情に仕上がっています。

4. 国産桧（四国・九州産等）

国産桧 一枚もの通常品フローリング ¥6,930 / ㎡ (税込 / 税抜 ¥6,300)
寸法：15mm×105mm×1920mm 産地：四国・九州産等 グレード：通常品 仕上：無塗装

主に四国・九州産の桧を使用した、一枚ものの通常グレードの無垢フローリングです。しっかりとした節が随所に現れ、天然木ならではの力強さと素朴な風合いを感じられる、味わい深い表情が魅力。木が本来持つ生命力や温もりを身近に感じられる仕上がりです。

国産桧 一枚もの上小節フローリング ¥11,880 / ㎡ (税込 / 税抜 ¥10,800)
寸法：15mm×105mm×1920mm 産地：四国・九州産等 グレード：上小節 仕上：無塗装

小さな節のみを厳選した、上小節グレードの無垢フローリングです。節の主張をほどよく抑えることで、通常品よりもすっきりとした端正な表情に仕上がっています。桧ならではの明るく清潔感のある木肌と、自然素材特有のやさしい風合いが、空間に上品な趣をもたらします。

国産桧 一枚もの無節フローリング ¥14,190 / ㎡ (税込 / 税抜 ¥12,900)
寸法：15mm×105mm×1920mm 産地：四国・九州産等 グレード：無節（最高峰） 仕上：無塗装

国産桧フローリングの中でも最高ランクに位置する「無節」グレードです。表面に節がなく、通直で緻密な木肌が織りなす、端正で美しい表情が大きな魅力。桧特有の明るく上品な色合いと、なめらかな木肌が空間に格調高い趣を添えます。
